Полный набор инструментов для управления донатами в реальном времени.

🚀 Мгновенные оповещения

Наше приложение для ПК синхронизируется с вашим телефоном и моментально перехватывает уведомления о переводах Kaspi, отправляя их на стрим.

🎤 Голосовая озвучка (TTS)

Каждый донат будет зачитан приятным голосом, чтобы вы не пропустили ни одного сообщения от ваших зрителей.

🎨 Полная кастомизация

Настраивайте виджеты оповещений, цели сбора, списки топ-донатеров и последних донатов под стиль вашего стрима.

🖥️ Поддержка OBS и TikTok

Сервис полностью совместим с OBS Studio, Streamlabs и TikTok Live Studio, позволяя легко интегрировать виджеты в вашу трансляцию.

Системные требования

Для корректной работы сервиса вам понадобится:

🖥️

Компьютер с Windows 10/11

Рекомендуется использовать Windows 11 для наилучшей стабильности.

📱

Телефон на Android

Для синхронизации уведомлений с ПК.

💨

Bluetooth на ПК

Необходим для установления связи между компьютером и телефоном.
